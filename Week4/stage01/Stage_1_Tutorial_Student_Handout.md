# Stage 1 Tutorial Activity - Why Software Engineering Still Matters

<h1><b> Activity 1 - Think-Pair-Share </b></h1>
<p><i> If ChatGPT or Copilot chan produce a 100-line Python application very quickly, what knowledge does a software engineer still need? </i></p>

1. Coding comprehension [the ability to understand the code]
2. Mathematical knowledge to help with code optimisation
3. Code security

<h1><b> Activity 2 - Is This Software Engineering? </b></h1>
<p><i> Scenario A: A student writes a 50-line Python calculator. <br>
Scenario B: A team develops a payroll system used by 5,000 employees. <br>
Scenario C: An AI assistant generates a simple appointment application from one prompt. </i></p>

<p><b> Programming? </b></p>
A. Yes <br>
B. No <br>
C. No 

<p><b> Software Engineering? </b></p>
A. No <br>
B. Yes <br>
C. No 

<p><b> Why? </b></p>

A. Software Engineering refers to applying systematic principles to design and build. Just programming doesn't mean that there was any planning there. <br>

B. A team was utilized to create the payroll system. With the team, there is planning, code reviewing and things that apply in the Software Engineering practice. <br>

C. AI Assistant doesn't plan for the project or manage a team. It's just given prompts and spits out snippets of code form the internet creating some sort of program. It doesn't really program either, just copy and pastes code snippets from the internet. 

<h1><b> Activity 3 -- SmartCare Problem Analysis </b></h1>
<p><i> Client statement: SmartCare Community Clinic currently uses spreadsheets and paper records to manage patients and appointments. The clinic wants new software to improve these processes. </i></p>

<h3><i> Task 1 -- Identify stakeholders </i></h3>

- The numbers match each other to act as some sort of table. I do this because I can't make a table in an MD file. 
<p><b> Stakeholder </b></p>

1. Patients
2. Receptionists
3. Docters 
4. Owner

<p><b> What do they need? </b></p>

1. An efficient program that can book and reschedule appointments quickly and safely. 
2. Fast way to check patients in and avoid double-bookings. Assistance in rescheduling appointments. 
3. Reliable access to patients' medical history and schedule. 
4. Reports on the number of patients. 

<h3><i> Task 2 -- Identify current problems </i></h3>

1. No real-time access [unless it's in google spreadsheets or something] 
2. Poor security [easy to access and easy to copy]
3. No version control [can't revert changes]
4. Potential scheduling conflicts [hard to see how many patients booked in a day] 

<h3><i> Task 3 -- Ask client questions </i></h3>

1. How many patients on average per day [or week/month. Just give a timeframe] 
2. Who needs to access the systems 
3. What operating systems is going to be used
4. What's the budget and timeframe

<h1><b> Exit question </b></h1>
<p><i> Write one activity that a software engineer must perform and that cannot safely be delegated entirely to AI. </i></p>

Code security is very important for software engineers. The moment this program gets compromised, the severity of the damage to the customers and business reputation will be incomprehensible. An AI cannot manage code security by itself, the code snippets that the AI may utilise can potentially have major issues in it and it is the software engineer's responsibility to clean up the mistakes.
